MOTION DIRECTION
Motion is INFORMATIONAL.
It should show:
prioritisation;
state changes;
filtering;
selection;
relationships between views.
Important sequence:
50 sites
→
47 recede
→
3 surface
→
1 selected
→
detail revealed
→
action becomes available.
This should be one of the defining experiences of the page.
Use MotionSites-like execution quality for transitions but retain the Sitescope logic.
Good techniques:
scroll-linked clipping;
controlled masking;
sticky stages;
staggered site-state changes;
opacity reduction for non-priority sites;
position interpolation;
detail-panel reveal;
counters changing as states filter.
Avoid:
random float loops;
constant movement;
excessive parallax;
bounce;
spinning objects;
generic fade-up applied to every section.
Once information has arrived, it should generally become still.
Respect prefers-reduced-motion.
Reduced-motion mode should preserve the narrative without requiring animation.

FINAL SELF-CRITIQUE
Before considering the site finished, inspect it as a creative director.
Ask:
Does the first viewport immediately communicate multi-site WordPress management?
Can I understand 47 healthy / 2 warning / 1 critical without studying the screen?
Is the product the visual centerpiece?
Does the 50→3 moment actually communicate the customer problem?
Does selecting each attention item work?
Does every color have a reason?
Does every motion have a reason?
Are there generic SaaS cards that could be removed?
Are there decorative shapes that don't communicate anything?
Could I replace “Sitescope” with an AI startup's name and have the page still make sense?
If yes, make the design more specific.
Does it accidentally feel like an admin-dashboard prototype rather than a premium marketing experience?
If yes, improve composition, scale, typography and storytelling.
Check every remote image.
Check every fallback.
Check every interaction.
Check mobile.
Check responsive transitions.
